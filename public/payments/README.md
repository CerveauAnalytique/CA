# Payment logos

These files are plain text badges so the footer works out of the box.
For the official logos, download them from https://www.mollie.com/resources (and Stripe's brand
assets), follow their usage guidelines, and save them here with the same file names
(ideal.svg, bancontact.svg, visa.svg, mastercard.svg, amex.svg, applepay.svg, paypal.svg, sepa.svg).
The footer picks them up automatically.
