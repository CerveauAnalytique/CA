# Languages

The site is available in English (`en`), Dutch (`nl`), German (`de`), French (`fr`), Spanish (`es`),
Polish (`pl`) and Arabic (`ar`, right-to-left).

- **Addresses start with the language code:** `/ar/models`, `/nl/datasets/ca7`. A link with a code opens the site in that language.
- **First visit:** the device language (`Accept-Language`) is used, English if it is not supported. The choice is kept in the `ca_lang` cookie.
- **Flag button** in the header (and the language links in the footer) change the language.
- **Accounts:** customers pick a language when signing up. It is saved as `users.language` (visible in the admin panel under Users) and used again when they log in. Changing the language while logged in updates it.
- `/admin` and `/api` have no language code.

## Translations

`src/i18n/translations/<code>.ts`, keyed by the English text. English is the source, so it has no file.

```tsx
const t = await getT()          // server components
const t = useT()                // client components
t('Add to cart')                // text
t('{n} rows', { n: 5 })         // with values
tr('Shop')                      // marks a text in a list/config; translate it with t() where it is shown
```

`pnpm test:int` fails if a text used with `t()` or `tr()` is missing in any language, if a `{placeholder}`
is lost, or if a translation is no longer used. To add a text: use it in the code, then add it to the six files.

Not translated: product, model, dataset and app names and descriptions (they come from the database),
page titles for search engines, and pages that do not use `t()` yet (they stay in English).
